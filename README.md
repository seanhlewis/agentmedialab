# Agent Studio

**Live:** https://seanhlewis.github.io/agentmedialab/

Every MAS.S60 (*AI Agents for Cognitive Augmentation*, MIT Media Lab, Fall 2026) classmate in one pixel room, seated at their week-8 tables. Click anyone to hear what they built in their own words, open any build's write-up, and jump to related classmates at other tables.

- **Studio:** the room. Click people, tables, the whiteboard and the pinboard.
- **Why:** why the room exists. It builds on Raine Sha's *From → To* in [Our Cognitive Gardens](https://mitmedialab.github.io/agents2026-raine/week04/): from 4 weekly highlights and a project list, to every build visible, with pairs and inspiration across the class.
- **Stats:** which people, tables and builds get opened, click-through rates, and whether opens lead on to the actual work.

## Data

| Path | What it is |
|---|---|
| `research/people/<id>.json` | Research for each person, taken only from their own course site (builds, summaries, lines, colours) |
| `research/raine-course-snapshot.json` | Raine Sha's source-reviewed catalog of 71 builds and Garden Agent pairs, from [MyGarden4.0](https://github.com/rainscyy/MyGarden4.0) (MIT License) |
| `data/people.js` | Generated by `python -I tools/build_data.py`; do not edit by hand |

If something about you is wrong, open an issue or edit your file in `research/people/`, then run `python -I tools/build_data.py`.

## Click stats without a database

No server, no database, no CI. `track.js` records anonymous events such as `person/raine`, `table/4`, `site/raine`, `build/raine/4` and `related/raine/jad`, plus per-person roll-ups `work/<id>` (clicked on to their site or a build) and `via/<id>` (arrived from a related or paired link). It uses no cookies and stores no names or IP addresses.

- Each visitor's own tally lives in their browser's localStorage (Stats → *Just you*).
- Class-wide, each event is also sent to [GoatCounter](https://www.goatcounter.com) (site code in `data/config.js`). The Stats tab reads totals straight back from GoatCounter's public read-only counter, `https://<code>.goatcounter.com/counter/<path>.json`, so the page computes CTRs live in the browser.
- The counter endpoint needs GoatCounter *Settings → Allow using the visitor counter* turned on.
- Full detail, including every event path and the dashboard, is at the GoatCounter site itself.
